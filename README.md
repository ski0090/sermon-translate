# 설교 영상 한국어 더빙

외국어 설교 영상에 입혀진 한국어 자막을 읽어 한국어 음성으로 만들고, 그 음성을 입힌 영상을 만드는 프로그램입니다.
Windows 또는 Ubuntu PC에서 혼자 쓰는 로컬 웹 프로그램이며 GPU는 필요 없습니다.

- 기획 문서: [reports/issue-0-1.md](reports/issue-0-1.md)
- 코드와 모듈 설명: [dubber/README.md](dubber/README.md)
- `caption_extractor/`는 이전 구현(Flutter + Rust + PaddleOCR)이며 더 이상 쓰지 않습니다.

## 준비물 (한 번만)

### Windows

1. **Python 3.10 이상** (3.13에서 개발·검증). Microsoft Store나 python.org에서 설치한 뒤 확인합니다.

   ```bash
   python --version
   ```

2. **ffmpeg**. [gyan.dev 빌드](https://www.gyan.dev/ffmpeg/builds/)의 `ffmpeg-release-full.7z`를 받아 압축을 풀고 `bin` 폴더(예: `C:\ffmpeg\bin`)를 PATH에 추가한 뒤 확인합니다.

   ```bash
   ffmpeg -version
   ```

3. **Python 패키지**.

   ```bash
   python -m pip install pillow numpy onnxruntime supertonic
   ```

### Ubuntu

Ubuntu 26.04(Python 3.14)에서 확인했습니다. 저장소 폴더에서 실행합니다.

1. **ffmpeg, venv**.

   ```bash
   sudo apt install ffmpeg python3-venv
   ```

2. **Python 패키지**. Ubuntu는 시스템 Python에 바로 설치할 수 없으므로 저장소 안에 가상 환경(`.venv`)을 만듭니다.

   ```bash
   python3 -m venv .venv
   .venv/bin/pip install pillow numpy onnxruntime supertonic
   ```

### 공통

1. **AI 명령줄 도구**. 자막 그림을 읽고 문장을 정리하는 데 씁니다. 기본은 Claude Code CLI이고 설정에서 Codex CLI로 바꿀 수 있습니다. 로그인된 상태여야 합니다.

   ```bash
   claude --version
   ```

2. 첫 실행 때 음성 엔진 Supertonic이 모델(약 300MB)을 자동으로 내려받습니다. 이때만 인터넷이 필요합니다.

3. **구글 드라이브**. 영상은 구글 드라이브에서 불러오고 결과물도 드라이브에 저장합니다. [rclone](https://rclone.org/install/)을 설치하고 `gdrive`라는 이름으로 연결합니다. 자세한 순서는 아래 [구글 드라이브 연결](#구글-드라이브-연결)에 있습니다.

## 실행

저장소 폴더에서 실행하면 브라우저가 자동으로 열립니다.

```bash
python dubber/server.py          # Windows
.venv/bin/python dubber/server.py   # Ubuntu
```

- 주소: http://127.0.0.1:8765
- 끝내기: 실행한 터미널에서 `Ctrl+C`
- 브라우저를 자동으로 열지 않으려면 뒤에 `--no-browser`를 붙입니다.
- 한 프로젝트 폴더에는 서버를 하나만 띄울 수 있습니다. 이미 실행 중이면 새로 띄운 서버는 안내를 내고 끝납니다. 시험용으로 다른 폴더를 쓰려면 환경 변수 `DUBBER_PROJECTS`에 폴더를 넣습니다.
- 화면 위쪽에 Claude 플랜의 남은 사용량(5시간 한도와 주간 한도의 남은 비율)이 나옵니다. AI를 부를 때마다 갱신되고, "확인"을 누르면 짧은 호출로 바로 알아봅니다(토큰이 조금 듭니다). 남은 토큰 개수는 Claude가 알려 주지 않아 비율로만 보여 줍니다.
- 같은 네트워크의 다른 PC에서 접속하려면 뒤에 `--lan`을 붙입니다. 터미널에 `다른 PC에서 접속: http://<이 PC의 IP>:8765/`가 나옵니다. 비밀번호가 없으므로 같은 네트워크의 누구나 접속할 수 있다는 점에 주의합니다. Ubuntu에서 방화벽(ufw)을 켜 두었다면 `sudo ufw allow 8765/tcp`로 포트를 엽니다.

## 구글 드라이브 연결

시작 화면의 "구글 드라이브에서 선택"으로 영상을 고릅니다. 고른 영상은 작업용으로 `dubber/projects/_drive/`에 내려받은 뒤 프로젝트로 만들며, 이미 받은 영상은 다시 받지 않습니다. "공유 문서함"을 체크하면 다른 사람이 공유한 파일도 볼 수 있습니다.

결과물은 원본 영상과 같은 드라이브 폴더 아래 `<영상 이름> 한국어 더빙` 폴더에 올립니다. 예를 들어 `2026 설교/주일 설교.mp4`의 결과물은 `2026 설교/주일 설교 한국어 더빙/`에 저장됩니다. 공유받은 폴더에 쓸 권한이 없으면 내 드라이브 맨 위에 같은 이름의 폴더를 만듭니다. 다시 내보내면 같은 이름의 파일을 덮어씁니다.

rclone의 공용 client_id는 2026년 중 사용이 중단되므로 본인 client_id를 만들어 씁니다.

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 프로젝트를 만들고 **API 및 서비스 → 라이브러리**에서 `Google Drive API`를 사용 설정합니다.
2. **Google 인증 플랫폼**에서 앱을 만듭니다. 회사 Workspace 계정이면 대상을 **내부**로, 개인 Gmail이면 **외부**로 하고 **대상 → 앱 게시**를 누릅니다(테스트 상태로 두면 7일마다 다시 로그인해야 합니다).
3. **클라이언트 → 클라이언트 만들기**에서 유형을 **데스크톱 앱**으로 만들고 클라이언트 ID와 보안 비밀번호를 복사합니다. "웹 애플리케이션"으로 만들었다면 승인된 리디렉션 URI에 `http://127.0.0.1:53682/`를 추가해야 합니다(없으면 `redirect_uri_mismatch` 오류).
4. 터미널에서 `rclone config`를 실행해 `n`(새 리모트) → 이름 `gdrive` → Storage `drive` → client_id와 client_secret 붙여넣기 → scope `1` → `service_account_file`은 **비워 둡니다** → 브라우저 로그인 순서로 진행합니다.
5. `rclone lsd gdrive:`로 폴더 목록이 나오면 연결된 것입니다.

리모트 이름을 `gdrive`가 아닌 다른 것으로 만들었다면 실행할 때 환경 변수 `DUBBER_GDRIVE`에 그 이름을 넣습니다. 내려받은 client_secret JSON 파일은 rclone이 쓰지 않으니 저장소 안에 두지 말고 지웁니다.

## 자동 진행

시작 화면의 "자동 진행"에서 목소리를 고르고 "시작"을 누르면, 끝나지 않은 JP 영상을 번호순으로 자막 읽기와 문장 정리까지 진행합니다: 프로젝트 만들기 → 자막 영역 자동 감지 → 자막 찾기 → AI 읽기 → AI 문장 정리. 여기서 멈추고("검수 대기"), 음성은 사람이 검수한 뒤 직접 시작합니다.

- Claude 사용량이 주간 80% 또는 5시간 50%를 넘으면 그 창이 초기화될 때까지 쉬어서 사람이 직접 쓸 몫을 남깁니다(기준은 `server.py`의 `USAGE_RESERVE`). 한도에 걸린 묶음은 빈칸으로 저장하지 않고, 한도가 풀리면 이어 갑니다.
- 자막 그림의 절반 이상을 못 읽으면 자막 영역을 다시 자동 감지합니다. 그래도 못 읽으면 "실패"로 표시하고 다음 영상으로 넘어갑니다. 3편이 연달아 실패하면 멈춥니다. 고친 뒤 "다시 시작"을 누르면 실패한 영상이 대기열에 다시 들어갑니다.
- JP 폴더에 같은 파일이 제목만 다르게 있으면 앞의 것만 만들고 뒤의 것은 "같은 영상이라 건너뜀"으로 표시합니다.
- 서버가 꺼졌다 켜지면 하던 영상의 그 단계부터 이어 갑니다. "멈추기"를 누르면 지금 하던 단계까지만 하고 멈춥니다.

## 음성 대기열

영상 화면의 "음성 만들기"는 바로 시작하지 않고 음성 대기열에 들어갑니다(화면에 "음성 대기 중 (앞에 n편)"). 음성 줄 4개가 대기열 앞에서부터 하나씩 맡아 음성 → 내보내기 → 드라이브 올리기를 하고, "중단"을 누르면 대기열에서 빠집니다. 서버가 꺼졌다 켜지면 하던 음성은 대기열에 다시 들어가 이어 만듭니다(이미 만든 문장은 그대로 씁니다).

- 한 편이 쓰는 CPU 스레드를 4개로 제한하고 4편을 동시에 만듭니다. 음성 엔진은 한 문장으로 코어를 다 쓰지 못해 여러 편을 같이 만드는 게 빠르지만, 작업마다 코어를 전부 쓰려 하면 서로 다퉈 오히려 느려집니다(16코어에서 제한 전 문장당 5.5초 → 제한 후 1.8초). 동시 편수와 스레드 수는 환경 변수 `DUBBER_VOICE_WORKERS`(기본 4), `DUBBER_TTS_THREADS`(기본 4)로 바꾸며, 둘을 곱해 코어 수쯤 되게 맞춥니다.

## 유튜브 업로드

완료된 영상은 프로젝트 목록의 "유튜브 올리기" 버튼으로 유튜브에 **비공개**로 올립니다. 제목은 `<영상 이름> (한국어 더빙)`이고, 재생목록 "조셉 프린스 더빙"(없으면 비공개로 만듭니다)에 넣으며, 한국어 자막(srt)도 함께 올립니다. 이 PC에 결과물이 없으면(다른 PC에서 만든 영상) 드라이브의 결과 폴더에서 받아 올린 뒤 지웁니다.

처음 한 번 준비합니다.

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 rclone용으로 만든 프로젝트를 고르고 **API 및 서비스 → 라이브러리**에서 `YouTube Data API v3`를 사용 설정합니다. OAuth 클라이언트는 rclone의 `gdrive` 리모트에 넣은 것을 그대로 씁니다.
2. 앱 대상이 **내부**(회사 Workspace)이면 회사 계정만 로그인할 수 있습니다. 유튜브 채널이 개인 계정에 있다면 대상을 **외부**로 바꾸고 **앱 게시**를 누릅니다.
3. **서버 PC의 브라우저**에서 시작 화면의 "유튜브 연결"을 누르고 채널 계정으로 로그인합니다("확인되지 않은 앱" 경고는 고급 → 이동). 로그인이 끝나면 시작 화면에 채널 이름이 나옵니다. 토큰은 `~/.config/dubber/youtube.json`에 저장됩니다.

알아 둘 점:

- 심사(YouTube API 감사)를 받지 않은 API 프로젝트로 올린 영상은 유튜브 정책상 비공개로만 둘 수 있습니다. 공개하려면 감사를 신청해야 합니다.
- 기본 할당량(하루 10,000 단위)으로는 하루에 약 4개(영상 1,600 + 자막 400 + 재생목록 50 단위)를 올립니다. 여러 개를 눌러 두면 차례로 올리고, 할당량이 떨어지면 태평양 시간 자정(한국 시간 오후 4~5시) 뒤에 자동으로 이어 갑니다.
- 올리는 중에 서버가 꺼지면 다시 켤 때 그 영상을 처음부터 다시 올립니다. 이미 올라간 영상은 다시 올리지 않고 남은 재생목록·자막만 합니다.
- 영상 설명과 해시태그는 시작 화면 유튜브 줄의 "설명·해시태그"에서 정합니다. 설명의 `{이름}`은 영상 이름으로 바뀌고, 해시태그는 설명 끝에 붙으며(앞의 3개가 제목 위에 보입니다) 영상 태그로도 들어갑니다. 새로 올리는 영상에만 적용되고, 이미 유튜브에 있던 영상의 설명은 바꾸지 않습니다.
- 재생목록 이름은 환경 변수 `DUBBER_YT_PLAYLIST`로 바꿉니다.

## 쇼츠

위쪽의 "쇼츠" 메뉴에서 음성을 다 만든 영상의 쇼츠(세로 1080×1920)를 만들고 검수합니다.

- **후보 고르기**: "Claude로 후보 3개 만들기"를 누르면 Claude가 문장 목록에서 앞뒤 설명 없이도 이해되는 30~60초 구간과 화면 위에 띄울 제목 두 줄, 강조할 구절을 고릅니다. "내보내기가 끝나면 자동으로 후보 3개 만들기"가 켜져 있으면 내보내기 뒤에 자동으로 고르고, 이때는 자동 진행처럼 Claude 사용량에 여유가 있을 때만 합니다. 고른 후보는 바로 영상으로 만듭니다.
- **화면**: 원본 영상의 자막 띠 위쪽을 잘라 가운데에 크게 두고, 배경은 같은 영상을 흐리게 깝니다. 소리는 더빙 음성이고, 자막은 더빙 음성에 맞춰 크게 새로 박습니다. 강조 구절은 노란색으로 조금 크게 쓰고 그 말을 하는 순간 테두리가 번쩍입니다.
- **검수**: 카드마다 제목, 구간(◀ ▶로 한 문장씩), 강조(글을 마우스로 고르고 "선택한 글 강조", 노란 글을 누르면 뺌), 가로 위치를 고칩니다. 고치면 왼쪽에 미리 보기 그림이 바로 나오고(문장을 누르면 그 장면), "다시 만들기"를 눌러야 영상에 반영됩니다. "직접 추가"는 더빙 영상의 시각을 적으면 그 문장부터 40초쯤을 새 쇼츠로 만듭니다.
- **저장**: `<영상 이름> 한국어 더빙/쇼츠/<영상 이름> 쇼츠 <번호>.mp4`로 만들고 구글 드라이브의 결과 폴더 아래 `쇼츠` 폴더에 올립니다. 만들기는 한 번에 하나씩 하며(대기열), 서버가 꺼지면 다시 켤 때 처음부터 다시 만듭니다.
- **유튜브**: 카드의 "유튜브 올리기"로 비공개로 올립니다. 유튜브 대기열에서 전체 영상보다 뒤에 올리고, 하루 할당량을 전체 영상과 같이 씁니다(쇼츠 하나에 1,600 단위). 제목과 설명은 "설명·해시태그"의 쇼츠 칸에서 정하고, 전체 영상이 유튜브에 있으면 설명에 그 주소를 넣습니다. 해시태그 앞에 `#Shorts`가 붙습니다.
- 자막 글꼴은 리눅스에서 Noto Sans CJK KR(Black), 윈도우에서 맑은 고딕을 쓰며 환경 변수 `DUBBER_SHORTS_FONT`로 바꿉니다. 아래쪽 문구는 `DUBBER_SHORTS_CREDIT`(기본 `조셉 프린스 설교 · {제목}`)로 바꿉니다.

## 사용 순서

1. **영상 불러오기**: 시작 화면에 구글 드라이브 `JP` 폴더의 영상이 모두 나오고, 영상마다 진행 상태(시작 전, 단계와 진행률, 완료)가 표시됩니다. "시작 전" 영상을 누르면 내려받아 프로젝트를 만들고 작업 화면으로 넘어가며, 작업 중인 영상을 누르면 이어서 엽니다. JP 밖의 영상은 "구글 드라이브에서 선택"으로 고르고, 그렇게 만든 프로젝트는 "다른 프로젝트"에 나옵니다. 목록은 1분마다 드라이브에서 다시 읽으며 "새로고침"으로 바로 읽을 수도 있습니다. 목록 폴더는 환경 변수 `DUBBER_LIBRARY`로 바꿉니다(기본 `JP`).
2. **자막 읽기**: 빨간 상자가 자막을 모두 덮고 성경 구절 상자는 피하는지 미리보기로 확인합니다. 어긋나면 y와 높이를 고치거나 "자동 감지"를 누릅니다. "자막 읽기 시작"을 누르면 자막이 바뀌는 순간 찾기, AI 읽기, AI 문장 정리까지 자동으로 이어집니다. 1시간 영상 기준 약 10분이 걸립니다.
3. **정리와 검수**: 아래 타임라인에서 잘라낼 구간을 정합니다. "자막 없음 · 찬양 후보 모두 잘라내기"를 누른 뒤, 제목 화면이나 마무리 화면처럼 남은 부분은 타임라인을 끌어서 선택하고 "선택 구간 잘라내기"를 누릅니다. 문장 목록에서 자막 그림과 읽은 글을 비교해 고치고, 그림 위의 "여기서 나누기"와 "다음 문장과 합치기"로 문장 단위를 맞춥니다. AI가 고친 글자는 노란색으로 표시되고 "되돌리기"로 되돌립니다. AI가 의심스럽다고 본 문장은 "확인 필요"로 표시되고 이유가 함께 나옵니다. 고칠 것이 없으면 "확인함"을 누릅니다. 잘라내기를 정한 뒤 "AI로 다시 정리"를 누르면 남은 자막으로 문장 목록을 새로 만듭니다(직접 고친 내용은 사라집니다).
4. **음성**: "들어 보기"로 목소리(여성 F1~F5, 남성 M1~M5)를 비교해 고르고 기본 속도를 정합니다. "음성 만들기"를 누르면 문장마다 음성을 만듭니다. 700문장에 약 1시간이 걸리고, 설정의 "빠름" 품질은 절반 정도입니다. "길이 초과"로 표시된 문장은 글을 줄이거나 속도를 올리고 "음성 다시 만들기"를 누릅니다. "영상과 함께 미리 듣기"로 전체를 들어 볼 수 있습니다.
5. **내보내기**: "음성 만들기"가 끝나면 모든 파일(영상, 오디오, 자막 srt, 자막 텍스트)을 원음 제거로 자동으로 내보냅니다. 다르게 만들려면 만들 파일과 원음 처리(제거 또는 낮춰서 깔기)를 고르고 "내보내기"를 다시 누릅니다. 만든 파일은 구글 드라이브에 자동으로 올라가며, 화면의 파일 이름을 누르면 지금 쓰는 PC로 내려받을 수도 있습니다.

결과 파일은 구글 드라이브의 `<영상 이름> 한국어 더빙` 폴더에 저장됩니다. 서버 PC의 `dubber/projects/<영상 이름>/<영상 이름> 한국어 더빙/`에도 같은 파일이 남습니다.
작업 내용은 단계마다 저장되므로 프로그램을 껐다 켜도 이어서 할 수 있습니다. 작업 중에 서버가 꺼지면 다시 켤 때 하던 단계(자막 읽기, 문장 정리, 음성 만들기, 내보내기, 드라이브에서 받기)를 그 단계의 처음부터 자동으로 다시 시작합니다. 이미 AI가 읽은 묶음과 만든 음성은 다시 만들지 않습니다. 같은 단계가 3번 연달아 끊기면 자동으로 다시 시작하지 않습니다.

## 설정

오른쪽 위 "설정"에서 바꿉니다.

| 항목 | 설명 |
|---|---|
| AI 도구 | claude 또는 codex |
| 한 묶음에 넣는 자막 수 | AI에 한 번에 보내는 자막 그림 수. 기본 25 |
| 동시에 읽는 묶음 수 | 기본 4. AI 호출이 느려지면 줄입니다 |
| 자막 없음 기준 시간 | 이 시간(초) 이상 자막이 없으면 잘라내기 후보로 표시. 기본 20 |
| AI 문장 정리 | 자막 읽기 뒤 AI가 문장 묶기, 글자 교정, 읽는 글(숫자, 영어, 장절), 확인 필요 표시를 할지 여부. 기본 켜짐. 끄면 규칙으로만 합칩니다 |
| 음성 합성 품질 | 표준 또는 빠름 |
| 읽기 사전 | 음성으로 읽을 때 바꿀 말. 한 줄에 `보이는 글=읽는 글` |

## 자주 겪는 문제

- **음성이 화면보다 늦게 들립니다.** 한국어 음성이 자막 표시 시간보다 길면 뒤 문장이 밀립니다. 음성 화면의 기본 속도를 1.10~1.15로 올리거나 긴 문장을 줄입니다.
- **자막 읽기가 멈춘 것처럼 보입니다.** AI 호출 하나에 수 분이 걸릴 때가 있습니다. 진행률의 묶음 수가 늘면 정상입니다. 계속 멈춰 있으면 "중단"을 누르고(진행 중인 호출이 끝난 뒤 멈춥니다) 설정에서 동시에 읽는 묶음 수를 줄여 다시 시작합니다. 이미 읽은 묶음은 다시 읽지 않습니다.
- **찬양 가사나 제목 화면이 음성으로 읽혔습니다.** 정리와 검수에서 그 구간을 잘라내기로 지정하면 문장 목록에서 빠지고 영상에서도 제거됩니다.
- **자막 영역에 성경 구절 상자가 들어옵니다.** 자막 읽기 화면에서 y 값을 키워 상자 아래로 내립니다.
- **목록에 "이전 작업 있음"이 나옵니다.** 다른 PC에서 작업한 기록(`<영상 이름>/project.json`)이 드라이브에 있지만 결과 영상은 없는 경우입니다. 누르면 처음부터 새로 작업합니다.
- **"구글 드라이브에 올리지 못했습니다"가 나옵니다.** 인터넷 연결과 `rclone lsd gdrive:`를 확인한 뒤 "내보내기"를 다시 누릅니다.
- **Ubuntu에서 `ModuleNotFoundError: No module named 'numpy'`가 납니다.** 시스템 Python(`python3`)으로 실행한 경우입니다. `.venv/bin/python dubber/server.py`로 실행합니다.
- **"구글 드라이브에서 선택" 버튼이 눌리지 않습니다.** `rclone listremotes`에 `gdrive:`가 있는지 확인합니다. 이름이 다르면 `DUBBER_GDRIVE`를 정합니다.

## 명령줄로 단계 실행

화면 없이 단계별로 돌릴 수도 있습니다. Ubuntu에서는 `python` 대신 `.venv/bin/python`을 씁니다.

```bash
python dubber/project.py new "<영상 경로>"
python dubber/project.py scan "<프로젝트 폴더>"
python dubber/project.py read "<프로젝트 폴더>"
python dubber/project.py sentences "<프로젝트 폴더>"
python dubber/project.py tidy "<프로젝트 폴더>"
```
