# 설교 영상 한국어 더빙 (dubber)

외국어 설교 영상에 입혀진 한국어 자막을 읽어 한국어 음성으로 만들고, 그 음성을 입힌 영상을 만드는 프로그램입니다.
기획 문서는 `reports/issue-0-1.md`에 있습니다.

## 처리 흐름

1. 영상 불러오기: 구글 드라이브(rclone)에서 영상을 고르면 PC로 내려받아 프로젝트가 만들어집니다.
2. 자막 읽기: 자막 영역의 그림이 바뀌는 순간을 PC 안에서 찾고(ffmpeg + numpy), 자막 그림을 25장씩 이어 붙여 AI 명령줄 도구(claude)에 읽힙니다. 영상 자체는 외부로 보내지 않습니다.
3. 정리와 검수: AI가 자막을 문장으로 묶고 글자를 고치고 읽는 글과 확인 필요를 붙입니다. 시간은 자막 번호로만 정하므로 AI가 틀려도 싱크는 깨지지 않습니다. 자막 그림과 읽은 글을 나란히 보며 고치고, 잘라낼 구간(찬양, 제목 화면 등)을 타임라인에서 지정합니다.
4. 음성: Supertonic(CPU, ONNX)으로 문장마다 한국어 음성을 만듭니다. 목소리 F1~F5, M1~M5.
5. 내보내기: 잘라내기 구간을 뺀 영상에 음성을 입힙니다. 영상(mp4), 오디오(mp3), 자막(srt), 텍스트(txt). 만든 파일은 구글 드라이브에 올립니다.
6. 쇼츠: Claude가 고른 30~60초 구간을 세로 영상으로 만듭니다. 더빙 음성에 맞춰 큰 자막을 새로 박고 강조 구절에 효과를 줍니다.

## 설치와 실행

설치, 실행, 화면 사용 순서는 저장소 루트의 [README.md](../README.md)에 있습니다.
프로젝트는 `dubber/projects/<영상 이름>/`에 저장되고, 결과 파일은 그 아래 `<영상 이름> 한국어 더빙/`에 만든 뒤 구글 드라이브의 원본 영상 폴더 아래 같은 이름의 폴더에 올립니다. 내보내기 중간 파일은 `work/`에 둡니다.

## 새 화면(Vue) 시험판

화면을 Vue로 옮기는 중입니다. `python webdev.py`(다른 PC에서도 보려면 `--lan`)를 실행하고 http://127.0.0.1:8766/ 을 엽니다.
지금 서버(8765)는 그대로 두고 옆에서 띄우며, `/api` 요청을 지금 서버로 넘기므로 데이터와 작업은 같습니다(새 화면에서 누른 것도 실제로 반영됩니다).
지금은 프로젝트 목록, 쇼츠, 음성 영상, 스케줄을 옮겼고, 프로젝트 작업은 지금 화면(`/old`)으로 엽니다. Vue는 빌드 없이 `web/vendor/vue.esm-browser.prod.js`(3.5.13) 파일 하나로 씁니다.

## 소요 시간 (GPU 없는 노트북 기준)

- 자막 바뀜 찾기: 1시간 영상에 약 30초
- AI 자막 읽기: 25장 묶음당 약 30초, 4묶음 동시 호출로 1,000장에 약 6분
- 음성 합성: 문장당 약 5초, 700문장에 약 1시간 (설정의 "빠름" 품질은 약 절반)
- 내보내기: 1시간 영상에 약 5분

## 음성 엔진으로 Supertonic을 쓰는 이유

GPU 없는 개인 PC에서 사용료 없이 한국어 음성을 쉽게 만들 수 있기 때문입니다.

- GPU가 필요 없습니다. ONNX Runtime으로 CPU에서 돌아갑니다. 이전 구현은 PaddleOCR GPU를 쓰느라 CUDA 설치와 DLL 경로 설정이 필요했는데, 새 구현에서는 GPU 의존을 뺐습니다.
- 설치가 간단합니다. `pip install onnxruntime supertonic`만으로 Windows와 Ubuntu에 설치되고 Python 3.13, 3.14에서도 돌아갑니다. PyTorch 기반 TTS처럼 무겁지 않고, 새 Python 버전을 기다릴 일도 적습니다.
- 사용료가 없고 오프라인으로 돌아갑니다. 첫 실행 때 모델(약 300MB)을 받은 뒤로는 인터넷이 필요 없습니다. 영상 한 편이 700문장쯤이고 자동 진행으로 여러 편을 날마다 만들기 때문에 클라우드 TTS는 비용이 계속 나옵니다.
- 한국어를 바로 지원하고 기본 목소리가 있습니다. `lang="ko"`로 합성하고 목소리 10종(F1~F5, M1~M5) 가운데 고르기만 하면 됩니다. 목소리를 복제하는 엔진처럼 참고 음성을 따로 준비하지 않아도 됩니다.
- 속도를 조절할 수 있습니다. 합성 단계 수(`total_steps`)로 품질과 속도를 맞춥니다. 표준은 8단계, 설정의 "빠름"은 4단계이며 시간이 약 절반입니다.

## 모듈

| 파일 | 역할 |
|---|---|
| `captions.py` | 자막 영역 자동 감지, 자막 바뀜 감지, 가사(노란 글씨) 판정, 자막 없음 구간 |
| `ai.py` | 자막 그림 묶음 만들기, AI 읽기(캐시, 반으로 나눠 재시도), AI 문장 정리(형식이 틀리면 규칙으로 합침) |
| `sentences.py` | 문장 합치기 규칙, 성경 약어 풀어 읽기, 읽기 사전 |
| `tts.py` | Supertonic 합성, 캐시, 목소리 예시 |
| `export.py` | 음성 배치(1.2배속 한도, 밀림, 고정 지점), 더빙 트랙, ffmpeg 내보내기 |
| `gdrive.py` | 구글 드라이브(rclone) 폴더 보기, 영상 내려받기, 결과 올리기 |
| `youtube.py` | 유튜브 로그인(OAuth), 영상 이어 올리기, 재생목록, 자막 |
| `sleepvid.py` | 자면서 듣는 설교 영상: 어두운 배경 + 제목 + 이퀄라이저 막대(직접 그림), 소리는 싱크 없이 이은 음성 |
| `shorts.py` | 쇼츠: Claude로 구간·제목·강조 고르기, 세로 영상 만들기(흐린 배경 + 자막 띠 위 영상 + ASS 자막), 미리 보기 그림 (`<프로젝트>/shorts.json`) |
| `server.py`의 자동 진행 | 영상 대기열을 자막 읽기 줄과 음성 줄로 나눠 한 편씩 끝까지 진행(`projects/_batch.json`) |
| `project.py` | 프로젝트 저장소와 문장 편집, 잘라내기 구간 |
| `server.py` | 로컬 웹 서버와 API (표준 라이브러리) |
| `static/index.html` | 화면(왼쪽 메뉴와 단계별 거르기, 프로젝트 목록, 프로젝트 작업) |
| `static/shorts.js` | 쇼츠 화면 |
| `static/sleep.js` | 음성 영상(자면서 듣는 설교) 화면 |
| `static/schedule.js` | 스케줄 화면(날마다 자동 작업이 쓸 Claude 사용량, `projects/_schedule.json`) |
| `webdev.py` | 새 화면(Vue) 시험판을 8766 포트에서 띄우는 개발용 서버. `web/`은 직접 내주고 나머지는 지금 서버로 넘김 |
| `web/` | 새 화면(Vue): `app.js`(메뉴, 사용량), `projects.js`(프로젝트 목록), `shorts.js`(쇼츠), `sleep.js`(음성 영상), `schedule.js`(스케줄), `lib.js`(공용) |
